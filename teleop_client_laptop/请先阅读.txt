Bunker 控制台 — 笔记本桌面客户端
================================

这个文件夹要拷到【笔记本本地硬盘】。不要在 Cursor 远程工程里双击。

一次性准备
----------
1. 整夹拷到笔记本并覆盖旧文件，例如：D:\teleop_client_laptop\
   （必须覆盖「打开网页控制台.bat」，旧版 UTF-8 中文注释会在 cmd 里乱码，
   表现为弹窗找不到文件 “!URL!”。）
2. （可选）笔记本安装 Python 并 `pip install -r requirements.txt` 后，
   双击会改成独立窗口；不装则打开 Chrome/Edge。
3. 一般不用改 teleop_client.conf：HOST 留空时，会按顺序探测
   172.18.101.12（当前校园网）和 59.79.233.120（原遥控网），
   谁的 :9101 通就打开谁。不要填 192.168.1.102（雷达网口）。
   若要固定某一台，再把 HOST= 写成那个 IP。
4. （可选）把「打开网页控制台.bat」发送到桌面快捷方式。
   请双击 .bat，不要用「打开网页控制台.url」（那是旧地址的手动备份）。

每次使用
--------
1. 工控机先开：开机服务 bunker-local，或手动 python3 run_local.py
2. 笔记本双击「打开网页控制台.bat」
3. 已装 pywebview 时弹出独立窗口；否则打开系统浏览器。点一下页面，输入密码，按 WASD。

没装 Python 时，同一个 .bat 会用 PowerShell 探测候选 IP，再打开系统浏览器。

打不开时
--------
- 窗口显示「连不上工控机网页」：改 IP 后点「重新连接」，或先开 run_local
- 能登录但车不动：先看底盘电压（低于 24V 先充电），再关遥控器
