## 一、为什么必须用 VNC（不要在 SSH / Cursor / PowerShell 里开 RViz）

- Windows 笔记本没有 ROS2，PowerShell 里没有 `rviz2`。
- SSH / Cursor 没有图形显示器，会报：`qt.qpa.xcb: could not connect to display` 然后崩掉。
- 校园网跨网段通常只放行 **SSH 22**，直接连工控机 `5900` 会被拦。
- 正确做法：RViz 开在工控机本机桌面 `:0`，再用 **SSH 隧道 + 浏览器 noVNC** 看这块桌面。

## 七、浏览器里那个页面是什么？（不是官方网站）

**不是** AgileX / Bunker 官网，也不是云端后台。

那是**本仓库自己写的本地遥控页**，进程跑在工控机上：

| 项目 | 说明 |
|------|------|
| 页面文件 | `chassis_lidar_drivers/teleop_web.html` |
| 网页服务 | `python3 teleop_web.py`，端口 **9101** |
| 真正发车 | `bunker_jetson/teleop_tcp_server.py --direct-can`，端口 **9100** |
| 数据流 | 笔记本浏览器 WASD → 工控机 `:9101` → TCP `:9100` → CAN `can1` → 底盘 |

标题「Bunker 本地控制台」只是我们起的名字。密码 `fafu123456` 也是仓库里的本地口令，不是厂家账号。

为什么不用 Cursor / SSH 里敲键盘：SSH 只有字符流、没有 keyup，松键停不下来。浏览器有 keydown/keyup，才能松键即停。

2. 不要开 `start_agent.sh`（会抢雷达 UDP 6699）。
3. 手持遥控器关掉或拨离遥控档，否则和网页抢车。
4. 浏览器打开：`http://59.79.233.120:9101`  
   校园网若打不开 9101，把 SSH 隧道改成同时转发 VNC 和遥控：

**RViz 里怎么看**

- 白色十字 `+`：画面旋转中心，不是车。
- 写着 `map` 的 RGB 轴：地图原点，**永远不转**。
- 写着 `base_footprint` / `base_link` 的 RGB：车。红 = 车头。转弯时红轴应转。
- 一长串小轴：里程历史（Keep≈100），不是很多辆车。
