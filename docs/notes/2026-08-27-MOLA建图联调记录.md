## 三、问题与解决

### 1. 工控机一度上不了网，MOLA 装不上

**现象**：雷达网 `192.168.1.1` 当默认网关时，`apt` 访问不了 ROS 源。

**原因**：有线口接的是雷达局域网，不出公网。

**处理**：连上能上网的 WiFi `FAFU_AUTO`，默认路由走 WiFi（metric 600），雷达网仍保留 `192.168.1.102`（metric 更大，不抢网）。装完 MOLA 不必拔雷达网线。

---

### 2. MOLA 启动后立刻退出：`libmola_metric_maps.so`

**现象**：收到第一帧点云后：

`Could not find 'libmola_metric_maps.so'`

**原因**：GICP/ICP 管线要动态加载该插件，`mola-lidar-odometry` 没有把它当硬依赖装上。

**处理**：

```bash
sudo apt install -y ros-humble-mola-metric-maps
```

库路径：`/opt/ros/humble/lib/aarch64-linux-gnu/libmola_metric_maps.so`  
`source /opt/ros/humble/setup.bash` 后能在 `LD_LIBRARY_PATH` 里找到。

---

### 3. 下一帧又崩：`RKNN search requires nanoflann>=1.5.1`

**现象**：补上 metric-maps 后，默认 GICP 管线报 nanoflann 版本不够。

**原因**：Ubuntu 22.04 自带 `libnanoflann-dev` 是 **1.4.2**。GICP 的协方差近邻要用 RKNN（≥1.5.1）。Humble 上的 MRPT 按旧头文件编出来，这条路径会直接抛异常。这是已知问题，当晚没有重编 ROS/MRPT。

**处理**：换官方 point-to-point ICP 管线（不走 RKNN）：

```bash
mola_lo_pipeline:=../pipelines/lidar3d-icp.yaml
```

ICP 质量约 0.87～0.95，位姿约 10 Hz，可以建图。

---

### 4. 满屏 `FilterDeskew` 警告

**现象**：`destination map has field 't'/'ring' but source map does not`。

**原因**：RoboSense 点云只有 xyz + intensity；MOLA 运动补偿还想要每点时间戳 `t` 和线号 `ring`，没有就填 0。

**处理**：车速慢时可以忽略，不影响 ICP。真正运动补偿以后再补每点时间戳。

---

### 5. `/lidar_odometry/pose` 几乎不动

**现象**：x/y 钉在约 `-0.03 m`，twist 全 0。

**原因**：车停着。毫米级抖动是正常的。

**处理**：建图必须慢速开/推车。停着只能看到当前位置周围的一圈墙。

---

### 6. SSH / PowerShell 里 `rviz2` 打不开

**现象**：

- 工控机 SSH：`qt.qpa.xcb: could not connect to display`，核心转储。
- Windows PowerShell：`source` / `rviz2` 不是 cmdlet。

**原因**：

- SSH 没有图形显示器。
- 笔记本是 Windows，没有装 ROS2 Humble。

**处理**：RViz 必须开在 **工控机本机桌面** `:0`：

```bash
export DISPLAY=:0
rviz2 -d /opt/ros/humble/share/mola_lidar_odometry/rviz2/lidar-odometry.rviz
```

RViz 里 Fixed Frame = `map`，看 `/lidar_odometry/localmap_points`。  
`/rslidar_points` 的 frame 是 `rslidar`，当前没有这条 TF，在 `map` 下会看不到。

---

### 7. ToDesk / Windows「远程桌面」看不了工控机

**现象**：

- 工控机没装 ToDesk；官网 ARM64 包从命令行下下来是网页而不是 deb。
- GNOME RDP：`grdctl` 卡在 DBus，3389 没在听；Windows `mstsc` 报 **0x204**。
- 直接连 `172.18.101.12:5900` 不通。

**原因**：

- ToDesk 客户端不在工控机上，Windows ToDesk 控不到。
- GNOME 远程桌面缺 TLS 证书，服务没起来。
- 笔记本 WLAN 是 `172.18.49.130/21`（网段 `172.18.48.0`），工控机是 `172.18.101.12/21`（`172.18.96.0`）。校园网跨网段往往只放行 SSH 22，**5900 被拦**。UFW 一开始也只放了 `172.18.96.0/21`，连本机 IP 都不在里面。
- TightVNC 官网在校园网打不开（`ERR_CONNECTION_CLOSED`）。

**处理**（最终能看桌面的方案）：

1. 工控机：`x11vnc` 镜像正在显示 RViz 的 `:0`（本机 `5900`）。
2. 工控机：`novnc` + `websockify`，网页只听 `127.0.0.1:6080`。
3. Windows PowerShell（窗口一直开着）：

```powershell
ssh -L 6080:127.0.0.1:6080 fafu_robot@172.18.101.12
```

4. 浏览器打开：`http://127.0.0.1:6080/vnc.html`  
   VNC 密码：当晚设的 `fafu123456`。

走的是已经能通的 SSH 22，不碰被墙的 5900 和 tightvnc.com。

---

### 8. 当前会话存不了图、关了就没了

**现象**：LocalMap 只在内存里，没有 `.simplemap` / `.mm`。

**原因**：第一次启动没开 `generate_simplemap`。

**处理**：停掉旧 MOLA（雷达、RViz、VNC 不停），用：

`maps/start_mola_mapping.sh`

打开 simplemap。走完场地后存图：

```bash
source /opt/ros/humble/setup.bash
ros2 service call /map_save mola_msgs/srv/MapSave \
  "{map_path: '/home/fafu_robot/Desktop/chassis_lidar_drivers/maps/lab'}"
```

定位模式（存图之后再用，当晚未跑完）：

`maps/start_mola_localization.sh`

RViz 里用 **2D Pose Estimate** 给一个初始位姿。定位模式下 LocalMap 不再长大，只更新车的坐标。
